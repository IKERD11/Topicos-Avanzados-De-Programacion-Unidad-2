# Bibliografía

A continuación, se presentan las fuentes consultadas y recomendadas para profundizar en los conceptos de componentes, paquetes y librerías, utilizados durante el curso.

1.  Python Software Foundation. (2024). *The Python Standard Library*. Recuperado de [https://docs.python.org/3/library/index.html](https://docs.python.org/3/library/index.html)
2.  Python Software Foundation. (2024). *Modules and Packages in Python*. Recuperado de [https://docs.python.org/3/tutorial/modules.html](https://docs.python.org/3/tutorial/modules.html)
3.  Flet Documentation. (2024). *Flet Controls and User Controls*. Recuperado de [https://flet.dev/docs/controls/](https://flet.dev/docs/controls/)
4.  Sommerville, I. (2015). *Ingeniería de software* (10.a ed.). Pearson Educación.
5.  Gamma, E., Helm, R., Johnson, R., & Vlissides, J. (1994). *Design Patterns: Elements of Reusable Object-Oriented Software*. Addison-Wesley.
